The work doesn't.

Free plugins for Claude Code that help with work too big for one session: keeping notes the next session can trust, and running several sessions side by side.

Plugins

Pick the one you need

  • programme v0.5.0 Read more → Lets a long project pick up where the last Claude Code session left off, instead of starting from scratch each time. Good fit work with one running thread that spans many sessions, where you'd otherwise ask "where were we?" You type /programme:init my-feature
  • herdr-sessions v0.1.0 Read more → Inside Herdr, open another Claude Code session beside this one, or message sessions that are already running, by starting your message with pane:, tab: or sessions:. Good fit you run Claude Code inside the Herdr app or the Herdr TUI. You type pane: run the tests and fix failures

Install

Two commands in Claude Code

  1. /plugin marketplace add longthread/claude-plugins

    Once. Adds this collection to Claude Code.

  2. /plugin install <name>@longthread

    For each plugin you want, for example /plugin install programme@longthread. It takes effect in your next session.
